## Concrete open evidence and bounded inference

1. **Microsoft text and exact selected component.** The selected macOS arm64 tree includes both the hashed `OneAuthInterop.LICENSE.txt` and the hashed `libOneAuthInterop.dylib`, plus its stamp declaring version `12.0.1`. This is stronger than a license filename alone, but is not a publisher-authored license-to-binary applicability map. The license's introduction refers to the software named above without naming a product there. Its §3(e) expressly withholds sharing/publishing/distributing/leasing/transferring the software; §1(c) also acknowledges separately governed third-party components. These are factual contents of the preserved publisher payload. An independently accessible, version-specific official web copy of this OneAuth text or a publisher explanation reconciling it with CLI §2 was not located. Third-party mirrors were not used as authority. **Inference:** applicability/redistribution scope for the accompanying dylib is an unresolved release evidence issue; neither a blanket prohibition on the whole CLI nor permission to ignore the text is established. Do not extrapolate it to an uninspected Windows payload.

2. **Native notice completeness remains unproved.** The selected Copilot tree has only CLI `LICENSE.md`, `SHA256SUMS.txt`, and `OneAuthInterop.LICENSE.txt` as separately named notice/license files. Its inventory also contains `runtime.node`, `msal-node-runtime.node`, `libmsalruntime_arm64.dylib`, `ripgrep/.../rg`, `tgrep/.../tgrep`, and computer/browser-use assets. The file inventory and top-level native BOM do not identify every component's exact upstream version, applicable license, required notice, or possible embedded notices. **Inference:** a publisher notice/component map for this exact platform payload is missing from the evidence; it is not proved that a particular additional notice is legally absent. No arbitrary current license was substituted for an unidentified bundled version.

3. **Application conditions remain a release decision.** `docs/security.md` expressly leaves the repository's independent license decision and full native notices/redistribution review open. CLI §2 requires an independently licensed surrounding product and material additional functionality. Retained notices and hash equality cannot establish those product/legal conditions by themselves.
