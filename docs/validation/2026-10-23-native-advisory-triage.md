# Native advisory triage — 2026-10-23

Retrieved 2026-10-23 UTC. This is an additive follow-up to the [selected macOS arm64 native inventory](redistribution-evidence.md) and its local read-only advisory comparison. The earlier local snapshot identifies packaged Python 3.13.17 with SQLite 3.53.1, Electron 45.0.0 with embedded Node 24.22.0, and a then-current development Node 26.10.0. The current setup/CI Node floor is 26.12.1. Those are component identities, not an application reachability or complete native binary assessment.
